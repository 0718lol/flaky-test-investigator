# 岔路人生

一个以年为刻度的未来人生推演工作台。它面向普通用户，支持自我探索，也支持创建并观察非自己的虚构人物。产品用第三人称呈现可能的现实人生轨迹，不把结果包装成命运结论。

## 当前雏形

- 人物空间统一管理自我探索与观察人物，人物档案包含生活上下文及身体、精神、关系、事业、金钱、追求、观念弹性七项起始画像。
- 新建人物先输入现实困局，再按信息缺口逐题回答 1 至 3 个问题；确认系统理解后选择三条路径之一，也可以输入自己的行动。
- 选择后的前三年按行动、代价、验证或再协商逐年揭晓，看完后可保存、换路或修改条件。
- 困局会被整理成事实、约束、关键变量和不确定项；每条路径展示行动机制、成立条件与复盘信号，每年展示“因为 -> 所以 -> 仍需观察”的因果链。
- 首次只保存三年可解释范围，不再把系统自动生成的十五年基线当作用户已经选择的版本。
- 首次从 2026 年开始观察三年；保存后可继续延伸五年。已有长期版本仍按五年窗口浏览，每年一个节点。
- 点击任意年度节点查看场景与状态，再从该年改写。当前年及后续节点会在同一条轨迹上重新推演。
- 改写先成为未保存草稿，不会立即增加版本；确认保存后才进入人物的版本列表，可与旧版本逐年对照。
- 人物画像只影响之后的新推演，不回写已保存轨迹。
- 版本、人物与最近记录保存在浏览器本地，并支持 JSON 导入和导出备份。
- 默认仍可纯前端运行；另提供可选的本地 AI 连接器，用结构化候选增强追问、路径和三年余波，失败时自动回到本地规则。人物可删除，模型配置和密钥可单独清空。

## 产品原则

模拟器呈现的是在当前假设下的一组可能轨迹，不是预测命运，也不能替代医疗、财务、职业或关系方面的专业建议。节点文案用于让状态变化可感知，关键变量仍应逐步接入用户自己的真实信息。

## 本地运行

这是一个零依赖静态页面。直接打开 [index.html](./index.html)，或使用静态文件服务器：

```sh
python3 -m http.server 8080 --bind 0.0.0.0
```

然后访问 `http://localhost:8080`。

## 产品托管

平台通过 [app.toml](./app.toml) 托管本目录，启动命令从 `$PORT` 读取端口并绑定 `0.0.0.0`。
