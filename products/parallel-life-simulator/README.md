# 岔路人生

一个以年为刻度的未来人生推演工作台。它面向普通用户，支持自我探索，也支持创建并观察非自己的虚构人物。产品用第三人称呈现可能的现实人生轨迹，不把结果包装成命运结论。

## 当前雏形

- 2026 年开始、默认观察 15 年，每年一个时间节点，时间跨度可调整为 10 / 15 / 20 年。
- 点击任意年度节点，查看场景、关系、能量与自由度的变化。
- 从任意节点继续分叉，或改写当前节点；原版本会保留在左侧的推演版本列表中。
- 可以创建人物，填写姓名、年龄、城市和当前身份。
- 版本、人物、最近保存记录都可保存到浏览器本地，不上传数据。
- 纯前端运行，没有外部 CDN、账户或 API Key；场景图层目前由本地 CSS 生成，后续可替换为真实 CG 素材。

## 产品原则

模拟器呈现的是在当前假设下的一组可能轨迹，不是预测命运，也不能替代医疗、财务、职业或关系方面的专业建议。节点文案用于让状态变化可感知，关键变量仍应逐步接入用户自己的真实信息。

## 本地运行

这是一个零依赖静态页面。直接打开 [index.html](./index.html)，或使用静态文件服务器：

```sh
python3 -m http.server 8080 --bind 0.0.0.0
```

然后访问 `http://localhost:8080`。

## 产品托管

平台通过 [app.toml](./app.toml) 托管本目录，启动命令从 `$PORT` 读取端口并绑定 `0.0.0.0`。
